PA-220 → PA-520 routing converter

Converts the legacy routing (virtual routers) in a PA-220 configuration to Advanced Routing (logical routers) for the PA-520. Everything happens in this browser window. The file is not uploaded anywhere.

1. Choose the PA-220 configuration

On the PA-220: Device > Setup > Operations > Export named configuration snapshot and pick running-config.xml.

2. Result

3. Next steps on the PA-520 (PAN-OS 12.1)

    vr2lr . Converts static routing and IPv4 BGP. OSPF, RIP, multicast routing and less common BGP features are reported, not converted.
